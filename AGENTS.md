# Workspace Guidelines for AI Agent

## 1. File Modification & Change Approval Policy
- **Ask Before Modifying Files**: Always explain the proposed changes and ask for confirmation before modifying, replacing, or overwriting existing files in the workspace.
- **Provide Previews/Plans**: Show clear diffs or an implementation plan detailing what will be updated so the user can review and approve beforehand.
- **Preserve Documentation and Core Functionality**: Maintain high design quality, type safety, and clean formatting across all components.
