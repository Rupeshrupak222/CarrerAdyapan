# Workspace Guidelines for AI Agent

## 1. Strict File Modification & Change Approval Policy
- **No Automatic File Edits**: The AI agent must **NEVER** edit, modify, replace, or overwrite workspace files automatically.
- **Mandatory Pre-Change Preview & Diffs**: For any requested changes, first present a clear implementation plan with detailed code previews and diffs of all affected files.
- **User Review & Manual Acceptance Required**: Wait for the user to review the proposed changes. The user has full authority to manually accept or reject files. Only proceed with modifying files after explicit user confirmation/approval.
- **Preserve Documentation and Core Functionality**: Maintain high design quality, type safety, and clean formatting across all components.
