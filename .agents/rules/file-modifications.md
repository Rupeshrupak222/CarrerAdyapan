# Manual Approval For File Modifications & Actions

- **Ask Before Editing**: Do not automatically modify, replace, or overwrite project files without first presenting the proposed changes or plan to the user and obtaining explicit approval.
- **Provide Clear Diffs/Plans**: Clearly specify which files and components will be changed and why, so the user can review before execution.
- **Safety First**: Wait for the user's confirmation before performing file writes, destructive operations, or major code alterations.
